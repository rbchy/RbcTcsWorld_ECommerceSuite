# E-Commerce Capability Map

| Capability | Project status |
|---|---|
| Authentication + roles (CUSTOMER/ADMIN) | Implemented (Module 0) |
| Product catalog/search | Implemented |
| Cart | Implemented (Module 1) |
| Orders (place, history, cancel) | Implemented (Module 2) |

| Returns/refunds | Implemented (Module 4): 30-day window, reason-based refund/restock rules |
| Reviews | Expansion target |
| Recommendations | Expansion target |
| Notifications | Expansion target |
| Audit/reporting | Expansion target |

This is an original educational/portfolio implementation inspired by common large-scale e-commerce capabilities; it is not Amazon source code or branding.
